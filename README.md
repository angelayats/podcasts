# PODCAST's · Calendari de gravacions

App per organitzar i calendaritzar les gravacions dels podcasts *La cara oculta de la lluna* i *Blanc & Negre*.

- **Versió definitiva:** https://angelayats.github.io/podcasts/
- **Versió de proves:** https://angelayats.github.io/podcasts-proves/

La versió de proves guarda les dades a part, així es poden provar canvis sense tocar les gravacions reals.

## Instal·lar-la
- **iPhone:** obre l'adreça amb Safari → Compartir → Afegeix a la pantalla d'inici.
- **Ordinador:** a Chrome o Edge, icona d'instal·lar de la barra d'adreces.
